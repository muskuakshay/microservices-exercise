# Enterprise Java Microservices Exercise

This repository contains two Spring Boot microservices.

## Services

### Product Service
- Port: 8081
- Manages products and inventory

### Cart Service
- Port: 8082
- Manages shopping carts

## Technology Stack

- Java 21
- Spring Boot
- Maven
- Spring Web
- Spring Data JPA
- SQL Server Driver
- Lombok
